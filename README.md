# EduSync – AI-Powered Student Education System

A full-stack web application connecting students, teachers and college
administrators in one platform.

## Features
- Student dashboard with attendance, assignments and progress tracking
- Teacher dashboard with subject management and notifications
- Admin panel for college management
- QR-based attendance system
- AI-powered personal tutor based on syllabus
- Assignment submission portal
- Online lectures with video calling
- LinkedIn-style college feed
- Real-time communication platform
- AI chat moderation

## Tech Stack
- **Frontend:** React.js
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL (Neon)
- **AI:** Groq API, RAG architecture
- **Deployment:** Vercel (frontend), Render (backend)
